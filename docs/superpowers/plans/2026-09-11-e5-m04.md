# E5 lote 4 — módulo M04 (lendo logs, erros e documentação): plano de implementação

**Goal:** Entregar o módulo M04 completo: cinco aulas (M04-01 a M04-05, a última é prática de leitura — não simulação), `module.yaml`, avaliação do M04 (15 itens + escrita + fala) e padrões novos e conservadores no catálogo de erros BR.

**Architecture:** Nenhuma mudança de schema, servidor ou cliente. Conteúdo + testes de guarda, como M02/M03. `checkLesson` e `checkAssessment` já são genéricos.

**Tech Stack:** inalterado. Nenhuma dependência nova.

**Spec:** `docs/planejamento/02-trilha.md` §M04 + formato de `03-exemplo-aula-M01-02.md` + spec do motor `…e5-m01-design.md` §4.

## Global Constraints

- **Branch:** `feat/e5-m04` a partir de `main` (M01–M03 mergeados). Sem push/PR sem pedido explícito. Conventional Commits.
- **YAML:** quote escalares com `#`, `: ` ou aspas iniciais; `''` para apóstrofo. Toda tag existe em `tags.yaml`. Mini-markdown só. `pnpm content:build` após editar `content/`.
- **Regras de conteúdo (spec §4.1):** `vocabulary` 12–16, `examples` ≥ 6, `variations` ≥ 2, `brErrors` ≥ 8, `dialogue` 6–10 falas, `listening` 6, `writing` 60–90 palavras com 3–4 restrições, `speaking.modeA` ≥ 12 frases-alvo e 45 s, `quiz` 8 itens ≥ 4 tipos com gabarito balanceado, `srsCards` 10–12, `review.preferTags` ≥ 3, `completion { quizMin: 0.75, writingMin: 3, speakingRequired: true }`.
- **M04 é REA/VOC** — speaking vira leitura em voz alta / resumo falado (a engine exige; é treino útil de prosódia técnica).
- **M04-05** = prática de leitura, não `[SIM]`: `dialogue` vira debrief das leituras em call; writing sobe para 80–120 palavras; `prerequisites: [M04-02, M04-03, M04-04]`; `durationMin: 40`.
- **Regex conservadoras:** padrões novos com disparo + guarda. Na dúvida, tag-only.
- **Testes:** partida 355. Nunca enfraquecer existente.
- **Verificação por tarefa:** `pnpm content:build && pnpm typecheck && pnpm test`.

### Task 3: aula M04-01 — anatomia de mensagens de erro

**Brief:** `expected X, got Y`, `failed to`, `unable to`, `denied`, `timed out`, `refused`, `not found`. O que cada forma promete e onde olhar primeiro. Cenário: `ImagePullBackOff` e um `permission denied` do Terraform lidos com método. Gramática: estrutura da mensagem de erro (verbo no passado + infinitivo); tags `vocab.errors, topic.reading, comp.reading, comp.vocabulary, br.giving-error, br.did-past`. `prerequisites: []`. `durationMin: 35`. Diálogo: Yuri e Ana leem dois erros reais linha a linha (6–8 falas). Erros BR: "it's giving error", "I didn't understood", "the log says me", "I readed", "for to fix".

### Task 4: aula M04-02 — stack traces e logs estruturados

**Brief:** ler de baixo para cima; `Caused by:`, `at com.x…`, níveis (ERROR/WARN/INFO), timestamp, correlation id, campos JSON. Cenário: stack trace de uma aplicação Java + log JSON do API gateway. Tags: `vocab.errors, vocab.observability, topic.reading, comp.reading, comp.vocabulary`. `prerequisites: [M04-01]`. `durationMin: 35`. Erros BR: reuso do módulo + "I finded the error", "the error is saying".

### Task 5: aula M04-03 — READMEs e docs oficiais

**Brief:** skimming por headings; `prerequisites`, `caveats`, `deprecated`, `breaking change`, `note/warning`, `since version`, `see also`. Cenário: doc do Helm e seção de upgrade do Terraform. Gramática: passiva nas docs ("is deprecated", "has been moved") — tag `gram.passive`. Tags: `topic.reading, comp.reading, comp.vocabulary, gram.passive, vocab.iac`. `prerequisites: [M04-02]`. `durationMin: 35`. Erros BR: "according with the docs", "more easy", "I am agree with the docs".

### Task 6: aula M04-04 — issues e PRs no GitHub

**Brief:** `steps to reproduce`, `expected vs actual`, `same here`, `can confirm`, `workaround`, `+1 on this`, `reproduced on`, `not stale`, `bump` (em issue). Cenário: issue do Argo CD — ler o report, confirmar com dados próprios, comentar com workaround. Tags: `topic.code-review, vocab.tickets-prs, comp.reading, comp.writing, br.i-am-agree, br.said-me`. `prerequisites: [M04-03]`. `durationMin: 35`. ## Riscos

- **`irregular-past` com lista curada**: cada forma precisa ser sempre errada ("sited"/"wined" são palavras reais — fora da lista). Guarda cobre formas corretas ("read", "seeded").
- **`for-to`**: "for to" é arcaico e seguro; vírgula antes ("for me, to X") não casa — conferir na guarda.
- **Estender padrões existentes** (`did-past`+`saw`, `doubt`+`had a`): regressão coberta pelos testes de guarda atuais + novos.
- **Leitura falada na avaliação**: speaking mode A em módulo REA pode parecer estranho — frases-alvo de resumo falado, pedagogicamente defensável.
