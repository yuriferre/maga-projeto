# Plano — E5/M06: Tickets, commits e PRs

Spec em `content/levels.yaml` (E5/M06): WRI/REA, pré-requisitos `M03` + `M04`, conclusão "Padrão + 5 textos avaliados ≥ 3,5/5" → `writingMin: 3.5` no `pass`. M06-05 é prática ("3 tickets + 2 PRs a partir de cenários"), sem flag `simulation` na trilha — mas segue o formato de integração (diálogo maior, fala de 60 s) por coerência com M04-05.

## Escopo

Só conteúdo + testes — o motor de avaliação já é genérico. Branch `feat/e5-m06` a partir de `main` (M01–M05 mergeados).

## Tarefas

- **T1**: `content/modules/M06/module.yaml` (`writingMin: 3.5`) + `tests/lessons-m06.test.ts` com guarda de cross-validation.
- **T2**: 4 padrões BR novos + tags + guardas de falsos positivos:
  - `br.steps-for` — "steps for reproduce" → "steps to reproduce" (calque de "passos para reproduzir")
  - `br.verify-if` — "please verify if" → "check whether/if" (calque de "verifique se")
  - `br.merge-in` — "merge in main" → "merge into" — só com nomes de branch (main|master|develop|feature|staging|prod), protege "merge in the changes"
  - `br.revert-back` — "revert back" → "revert" (redundante; comum em contexto git)
- **T3–T7**: aulas M06-01 a M06-05 (`checkLesson`, formato padrão):
  - M06-01: ticket (título, contexto, steps to reproduce, expected × actual) — `gram.imperative` para steps
  - M06-02: commit messages e títulos de PR (imperativo, escopo, conventional commits) — `gram.imperative`
  - M06-03: PR description (what / why / how to test / risks)
  - M06-04: comentar em PRs (good catch, addressed, PTAL, nit:, LGTM) — `topic.code-review`
  - M06-05: prática integrada — 3 tickets + 2 PRs a partir de cenários (`durationMin: 45`, fala 60 s)
- **T8**: `assessment.yaml` — 15 itens cobrindo as tags `gram/br/vocab` reais do módulo; escrita = "3 tickets + 2 PRs" viram textos condensados dentro do limite do motor; testes de variantes para itens com duas correções.
- **T9**: validação via API na cópia do banco, `AGENTS.md`, plano, ledger, build.

## Riscos

- **`merge-in`**: restrito a nomes de branch para não pegar "merge in the changes".
- **`verify-if`**: "verify if" aparece em inglês nativo informal; ainda assim é calque clássico e a correção ("check whether") é sempre segura.
- **Conclusão "5 textos ≥ 3,5"**: o motor tem uma nota de escrita por avaliação — a escrita pede os 5 textos condensados; desvio registrado.
- **M06 é WRI/REA sem SPK na trilha**: o schema/checklist exige `speakingRequired` e o checklist espera `maxSeconds` — aulas mantêm modo A (45/60 s) como prática de leitura em voz alta; a avaliação mantém a fala do motor.
