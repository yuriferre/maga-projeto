# Plano — E5 M08: Retrospectivas e 1:1s

## Objetivo

Segundo módulo do Nível 2. Spec (`content/levels.yaml`): falar de problemas do
time sem culpar, dar e receber feedback, conduzir um 1:1 com objetivo.
Competências SPK/CNF; pré-requisito M02; conclusão "Padrão". M08-05 é `[SIM]`
(retro + 1:1, dois cenários curtos).

## Tarefas

- **T1** — `module.yaml` (pass padrão 0.75/3/3) + `tests/lessons-m08.test.ts` com `checkLesson`.
- **T2** — tags novas (`vocab.feedback`, `topic.retro`, 3 `br.*`) e 4 padrões BR com guardas de FP:
  - `team moral` → *team morale* (falso amigo: moral = ética; moral do time = morale)
  - `do a mistake` → *make a mistake* (calque de "fazer um erro")
  - `I'm boring/confusing/…` → *bored/confused* (-ing no lugar de -ed na 1ª pessoa; lista fechada, protege "they're annoying")
  - extensão do `uncountable`: `a/this/that/one/another feedback` → *some feedback / a piece of feedback* (lookahead protege "a feedback loop/signal")
- **T3–T7** — 5 aulas no formato estabelecido (M08-05 = simulação: 45 min, diálogo ≥ 12, listening 8, fala 60 s, pré-requisitos em cadeia):
  - M08-01 retro: what went well / what didn't / action items
  - M08-02 feedback construtivo: I noticed, it would help if
  - M08-03 recebendo feedback: fair point, I'll work on that
  - M08-04 1:1 com gestor: prioridades, carga, carreira
  - M08-05 retro + 1:1 (dois cenários curtos)
- **T8** — avaliação do módulo: 15 itens cobrindo as tags `gram/br/vocab` reais das aulas + variantes dos itens com duas correções.
- **T9** — validação via API na cópia do banco, `AGENTS.md`, resultado no plano.

## Riscos

- `i-am-boring` tem FP teórico ("I'm annoying" pode ser autoavaliação legítima) —
  restrito à 1ª pessoa + lista fechada de particípios de emoção.
- `moral→morale` restrito a sujeitos de grupo (team/group/company/crew/squad)
  para não pegar "the moral of the story".
- Sem tag existente para o domínio: `vocab.feedback` + `topic.retro` entram no T2.
