# Plano — E5 M09: Code review

## Objetivo

Terceiro módulo do Nível 2. Spec (`content/levels.yaml`): sugerir, pedir
mudanças e responder reviews com tom certo e vocabulário preciso.
Competências WRI/REA/VOC; pré-requisito M06; conclusão "Padrão + 6
comentários de review avaliados ≥ 3,5/5" — `writingMin: 3.5` no módulo,
mesmo precedente do M03/M06.

## Tarefas

- **T1** — `module.yaml` (pass 0.75/3.5/3) + `tests/lessons-m09.test.ts` com `checkLesson`.
- **T2** — tag `vocab.review` + 4 padrões BR com guardas de FP:
  - `did a comment` → *left a comment* (calque de "fiz um comentário"; protege "did a review" e "made a comment", que é inglês válido)
  - `seems me` → *seems to me* (calque de "me parece"; protege "seems to me", "he seems tired")
  - `according to me` → *in my view* / *I think* ("segundo eu"; "according to the docs" não dispara — o padrão exige "to me")
  - `it worths` → *it's worth it* / *worth doing* ("vale a pena"; protege "worth it")
- **T3–T7** — 5 aulas no formato estabelecido (M09-05 = prática/integração: diálogo ≥ 10, listening 8, fala 60 s, pré-requisitos em cadeia):
  - M09-01 sugerir sem impor: consider, what do you think about, nit:, non-blocking, suggestion
  - M09-02 pedir mudanças: this would break…, could we…, severidade explícita (blocking × nit)
  - M09-03 responder reviews: good catch, addressed in abc123, discordar com motivo, PTAL
  - M09-04 léxico de review: refactor, extract, dead code, edge case, race condition, magic number
  - M09-05 prática: revisar 3 PRs + responder 3 reviews (formato integração)
- **T8** — avaliação: 15 itens cobrindo as tags `gram/br/vocab` reais + variantes dos itens com duas correções. Escrita = os 6 comentários condensados (motor dá uma nota — mesmo desvio do M06).
- **T9** — validação via API na cópia do banco, `AGENTS.md`, resultado no plano.

## Riscos

- `seems me` tem FP teórico nulo com a lista fechada de pronomes; `according
  to me` é erro conhecido de ESL, seguro.
- "6 comentários ≥ 3,5" vira `writingMin: 3.5` — a avaliação condensa os
  comentários num texto só (o motor tem uma nota de escrita), mesmo desvio
  registrado no M03/M06.
