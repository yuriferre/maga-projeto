# Plano — E5 M10: Explicando problemas e soluções

## Objetivo

Quarto módulo do Nível 2. Spec (`content/levels.yaml`): narrar um problema,
o que foi tentado, a causa e a solução — em voz e em texto. Competências
SPK/WRI; pré-requisitos M04+M05; conclusão "Padrão". M10-05 é `[SIM]`
(explicar um bug e a correção numa thread e em voz).

## Tarefas

- **T1** — `module.yaml` (pass padrão 0.75/3/3) + `tests/lessons-m10.test.ts`.
- **T2** — tag `vocab.troubleshoot` + 4 padrões BR com guardas de FP:
  - `it not works` → *it doesn't work* (auxiliar ausente; lista fechada de verbos de infra)
  - `after/before/without to X` → *after doing X* (gerúndio após preposição; sempre errado)
  - `the same problem of` → *the same problem as* ("o mesmo X de ontem"; protege "same kind of")
  - `works in my machine` → *works on my machine* (calque "na minha máquina"; protege "machine learning")
- **T3–T7** — 5 aulas (M10-05 = simulação: diálogo ≥ 10, listening 8, fala 60 s, pré-requisitos em cadeia):
  - M10-01 narrativa: symptom → context → what I tried → what I found
  - M10-02 causa e efeito: turned out, because of, which caused, led to
  - M10-03 verbos de troubleshooting: narrow down, rule out, reproduce, roll back, bisect
  - M10-04 propondo solução: the quickest fix is…, the proper fix is…
  - M10-05 simulação: bug e correção em thread + voz
- **T8** — avaliação: 15 itens cobrindo as tags `gram/br/vocab` reais + variantes.
- **T9** — validação via API na cópia, `AGENTS.md`, resultado no plano.

## Resultado

Executado em 2026-09-12. 5 aulas + avaliação + 4 padrões BR (`it not works`,
`after/before/without to X`, `same X of`, `in my machine`) + tag
`vocab.troubleshoot`. `content:validate`: 50 aulas, 110 tags, 53 padrões;
688 testes, typecheck e build verdes. API na cópia: elegível 5/5 → finish
prematuro 409 → ref errado 400 → escrita 4 (0 findings) → fala 4,5 →
aprovado → segundo finish 409. Desvios: nenhum além dos previstos —
padrões estreitos com listas fechadas, `br.steps-for` reutilizado (o id da
tag difere do id do padrão).

## Riscos

- `it not works` restrito a pronomes + lista de verbos de infra para não pegar
  "that not withstanding" e frases fragmentadas legítimas.
- `same X of` com lista fechada de substantivos — "same kind of" é inglês
  correto e fica fora.
- Sem tag para o domínio: `vocab.troubleshoot` entra no T2
  (`vocab.incident`/`topic.incident-call` já existem para M12+).
