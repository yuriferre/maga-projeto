## Riscos

- `is -ing since` com sujeito nominal: restringir a substantivos de
  infra (pod/job/deployment/service/node/container) para não pegar
  narrativa legítima tipo "he was working since…" (também errada, mas
  fora do escopo conservador).
- `in the node` precisa de lookahead para `group|pool|list` — "scheduled
  in the node pool" é inglês aceitável.
- `need + verbo nu`: lista fechada (see/check/restart/describe/tail/get/
  watch/verify) — "need review the PR" fora.
