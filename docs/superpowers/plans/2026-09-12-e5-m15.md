# M15 — Comunicação de incidentes

Spec (trilha, nível 3): WRI+SPK, pré-requisitos M10+M03, completion
"Padrão + sequência de 4 atualizações escritas ≥ 4/5" → pass.writingMin
4 (precedente M13); as "4 atualizações" condensam numa escrita só
separada por `---` (mesmo desvio de M03/M09/M13 — o motor tem uma nota
de escrita por avaliação).

## Tarefas

- **T1** — `module.yaml` + esqueleto `tests/lessons-m15.test.ts`.
- **T2** — 4 padrões BR de comunicação de incidente + tags + guardas:
  - `in this moment` → right now / at this moment ("neste momento")
  - `thanks for the patience` → your patience / bearing with us
  - `as soon possible` → as soon as possible
  - `the service normalized` → recovered (sujeitos: service/api/site/
    system/app — "normalizou" é calque; "we normalized the data" fica
    fora porque o sujeito é restrito)
- **T3–T7** — 5 aulas:
  - M15-01 severidades e impacto (SEV1–4, customer-facing, degraded,
    partial outage, blast radius)
  - M15-02 primeira atualização (what / impact / status / next update)
  - M15-03 atualizações periódicas (investigating → identified →
    mitigated → monitoring)
  - M15-04 stakeholders não técnicos (sem jargão, com confiança)
  - M15-05 encerramento (resolved + post-mortem com prazo)
- **T8** — avaliação: 15 itens cobrindo as tags reais + variantes.
- **T9** — validação via API na cópia, AGENTS.md, resultado no plano.

## Resultado

- **T1–T9 completos** — 8 commits na `feat/e5-m15` (sem push/merge).
- `content:validate`: 5 níveis, **75 aulas, 132 tags, 73 padrões**.
- Suíte: **45 arquivos, 919 testes** — typecheck e build limpos.
- API na cópia do banco: elegível 5/5 → `finish` prematuro 409 →
  15 itens → ref inválida 400 → escrita 4 (0 findings) → fala 4,5
  (58 s) → **aprovado com writingMin: 4** (`module|M15`) → segundo
  `finish` 409.

## Desvios

- As "4 atualizações escritas ≥ 4/5" condensam numa escrita só com
  quatro blocos separados por `---` (mesmo desvio de M03/M09/M13 —
  o motor tem uma nota de escrita por avaliação).
- M15-05 não é `simulation: true` na trilha — ficou como aula de
  fechamento com escrita integrada (resolved + recap) e fala de 60 s.
- `brErrors` das aulas reutilizam tags do catálogo; só as tags de
  quiz/listening/lesson entram na guarda de cobertura da avaliação.
