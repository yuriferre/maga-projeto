# M16 — Incident calls (bridges)

Spec (trilha, nível 3): SPK+LIS+CNF, pré-requisitos M15+M02-04,
"Padrão + simulação ≥ 3/5" → pass padrão (itens ≥ 75 %, escrita ≥ 3,
fala ≥ 3). M16-05 é `simulation: true` — bridge de 15 min com 3
personas, usuário como incident commander.

## Tarefas

- **T1** — `module.yaml` + esqueleto `tests/lessons-m16.test.ts`.
- **T2** — 4 padrões BR de bridge + tags + guardas:
  - `confirm me` / `say me` → confirm / tell me ("me confirma")
  - `listen you` → hear you / listen to you ("te escuto")
  - `the call fell` → the call dropped ("a ligação caiu"; sujeitos
    restritos a call/connection/line — "night fell" fica fora)
  - `stay in the line` → on the line ("fica na linha"; verbos
    restritos a stay/hold/wait)
  - + tag `vocab.bridge` (papéis e protocolo de bridge)
- **T3–T7** — 5 aulas:
  - M16-01 papéis e protocolo (IC, scribe, comms lead, quem fala
    quando)
  - M16-02 informação sob pressão (can someone confirm, I'm seeing,
    say again)
  - M16-03 decidindo (let's roll back, I'd rather, hold off on,
    go ahead)
  - M16-04 interromper e realinhar (hang on, let's stay on, take it
    offline)
  - M16-05 [SIM] bridge de 15 min com 3 personas — usuário é o IC
- **T8** — avaliação: 15 itens + variantes.
- **T9** — validação via API na cópia, AGENTS.md, resultado no plano.


## Resultado (12/09)

- **T1–T9 completos.** 80 aulas, 137 tags, 77 padrões BR, 965 testes.
- 4 padrões novos: `confirm-me` (confirm/say/reply/answer + me),
  `listen-you` (listen + pronome sem to), `call-fell` (sujeitos
  call/connection/meeting/line — "night fell" fora), `in-the-line`
  (verbos stay/hold/wait/stand — "in line" a fila fica fora).
- M16-01 papéis/protocolo · M16-02 informação sob pressão · M16-03
  decisões (let's / I'd rather / hold off on / go ahead) · M16-04
  interromper e realinhar (hang on, park it, quick correction) ·
  M16-05 simulação: bridge completa como IC (14 falas).
- Avaliação: 15 itens cobrindo as 18 tags (17 br + vocab.bridge);
  7 testes de variante; escrita = recap da bridge com timeline;
  fala 60 s como IC.
- API na cópia (DB_PATH=data/progress-test.sqlite): elegível 5/5 →
  finish prematuro 409 → 15/15 → ref inválida 400 → escrita 4 →
  fala 4,5 (55 s) → aprovado → segundo finish 409.

### Desvios

- O helper conta MC de listening + quiz juntos no balanço do
  gabarito — três aulas precisaram de rebalanceamento após o RED.
- `brErrors` das aulas só referenciam tags existentes: M16-03/04/05
  reutilizam `do-modal`, `for-to`, `said-me`, `sorry-for-interrupt`,
  `explain-me`, `need-that-you`, `send-to-me`, `ask-to`.
- O YAML exige `''` (não `\'`) para apóstrofo dentro de escalar
  single-quoted — corrigido em três pontos.
