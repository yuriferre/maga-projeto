Spec (trilha, nível 3): WRI; gram.passive-blameless, gram.timeline;
pré-requisitos M15+M13; "post-mortem ≥ 4/5" → `writingMin: 4`
(precedente M13/M15).

## Tarefas

- **T1** — `module.yaml` (`writingMin: 4`) + esqueleto
  `tests/lessons-m17.test.ts` + branch `feat/e5-m17`.
- **T2** — 4 padrões BR de post-mortem + tags + guardas:
  - `in Friday` → `on Friday` (lookahead `'` protege "in Friday's
    post-mortem")
  - `was wrote/ran/forgot/chose/spoke` → particípio (lista fechada
    de passados irregulares depois de was/were/been)
  - `contributed for` → `contributed to` (só formas verbais —
    "a contribution for the victims" fica fora)
  - `the incident of Friday` → `Friday's incident` (lista fechada
    de substantivos + dias)
  - + tags `vocab.postmortem`, `gram.passive-blameless`,
    `gram.timeline`
- **T3–T7** — 5 aulas:
  - M17-01 cultura blameless ("the change", não "John's change";
    voz passiva útil)
  - M17-02 timeline (horários, timezones, "alerts fired",
    "was paged", "rolled back")
  - M17-03 root cause e contributing factors ("the underlying
    cause", "exacerbated by", "went unnoticed because")
  - M17-04 action items (owner, prazo, verbo de ação, prioridade)
  - M17-05 prática: post-mortem completo a partir de timeline crua
- **T8** — avaliação: 15 itens cobrindo as tags + variantes;
  escrita = post-mortem completo (`writingMin: 4`).
- **T9** — validação via API na cópia, AGENTS.md, resultado no plano.

## Resultado (14/09)

- **T1–T9 completos.** 85 aulas, 144 tags, 81 padrões BR, 1010 testes.
- 4 padrões novos: `in-weekday` ("in Friday"→on; `'` protege
  "in Friday's post-mortem"), `was-past` (was+wrote/ran/forgot —
  só passados ≠ particípio; "was lost/told" são corretos),
  `contributed-for` (só formas verbais — "a contribution for" fica
  fora), `of-weekday` (substantivos de incidente + dias —
  "Friday's incident").
- M17-01 cultura blameless · M17-02 timeline (TTD/TTR) · M17-03
  trigger×causa×fatores · M17-04 action items executáveis ·
  M17-05 o documento completo.
- Avaliação: 15 itens cobrindo as 16 tags (12 br + 3 gram +
  vocab.postmortem); 6 testes de variante; escrita = post-mortem
  completo com `writingMin: 4`; fala 60 s.
- API na cópia: elegível 5/5 → finish prematuro 409 → 15/15 →
  ref inválida 400 → escrita 4 (≥4 exigido) → fala 4,5 (55 s) →
  aprovado → segundo finish 409.

### Desvios

- `was-past`: a lista inicial misturava passados puros com
  particípios idênticos (was lost/told são corretos) — a lista
  final só tem formas que nunca são particípio, e o lookahead
  desnecessário foi removido (era ele que escondia o erro
  canônico "was wrote by").
- `reorder` exige tokens de uma palavra — "the cause" como token
  único quebra a checagem; tokens separados.
