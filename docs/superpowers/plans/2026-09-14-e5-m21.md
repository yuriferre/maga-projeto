# Plano — E5 · M21 · Defendendo decisões técnicas (Nível 4)

## Spec (docs/planejamento/02-trilha.md)

- **Objetivo:** argumentar uma decisão com estrutura, lidar com
  pushback e admitir limites.
- **Competências:** SPK, WRI, CNF; `gram.argument-connectors`.
- **Pré-requisitos:** M10, M14.
- **5 aulas:**
  1. Estrutura: context → options → decision → rationale →
     consequences
  2. ADRs: escrever e discutir; "we chose X over Y because…"
  3. Pushback: "that's a fair concern, however…", "I hear you,
     and…", "let me address that"
  4. Limites: "we don't know yet", "I'd want to validate that
     before committing", "I might be wrong about…"
  5. **[SIM]** Defender decisão em design review com 2
     revisores céticos
