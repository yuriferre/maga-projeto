"30 itens + post-mortem + sequência de updates + simulação de
bridge. Aprovação: ≥ 75%, post-mortem ≥ 4/5, bridge ≥ 3/5."

## Decisões

- Escrita em duas partes separadas por `---`: post-mortem
  (trigger × root cause × contributing × action item,
  blameless) + três updates (investigating → identified →
  resolved). `writingMin: 4` honra "post-mortem ≥ 4/5".
- Fala = simulação de bridge como IC, 90 s. `speakingMin: 3`
  honra "bridge ≥ 3/5".
- 30 itens cobrem as 45 tags gram/br/vocab de M15–M20
  (17 correções de erro com 2 tags carregam os 33 br.*).
- 4 testes novos em tests/level-assessment.test.ts.
