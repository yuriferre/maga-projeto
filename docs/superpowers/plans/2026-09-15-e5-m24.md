# M24 — Apresentações e demos

Spec: `docs/planejamento/02-trilha.md` (M24). Objetivo:
apresentar 5–10 min com estrutura, descrever slides/diagramas,
fazer demo e lidar com Q&A. Competências SPK, PRO, CNF.
Pré-requisitos M05 + M18.

## Tarefas

- T1: branch `feat/e5-m24` + `module.yaml` + esqueleto `tests/lessons-m24.test.ts`
- T2: 4 padrões BR novos (make a question → ask; in the
  screen → on; the graphic shows → graph/chart; I want that
  you see → want you to) + tags `vocab.presentation` e
  `gram.signposting`
- T3: M24-01 — estrutura e signposting ("I'll start with…",
  "moving on to…", "that brings me to…", "to wrap up…")
- T4: M24-02 — descrever diagramas e slides ao vivo; ritmo e
  pausas
- T5: M24-03 — demos: narrar enquanto executa, "while this
  runs…", falhas ao vivo sem pânico
- T6: M24-04 — Q&A: ganhar tempo, reformular, "good
  question", não saber com elegância
- T7: M24-05 — [SIM] apresentar 5 min sobre projeto próprio
  (gravado, rubrica)
- T8: avaliação 15 itens + testes de variante
- T9: docs, validação API e fechamento

## Desvios registrados

- M24-02: o reorder precisava de dois "the" nos tokens —
  a resposta o usava duas vezes; tokens corrigidos.
- M24-03: constraint "A admissão com plano" do writing
  aceitava só "don't" — o modelo usava "didn't"; o padrão
  foi ampliado para os dois tempos verbais (e "get back to
  \w+" em vez de só "you", pois o modelo diz "get back to
  him").
- M24-05: o plano de Q&A do modelo dizia "Q&A: rephrase…"
  sem a palavra "questions" — modelo reescrito para casar
  com a constraint.
- Avaliação: `\'` inválido em double-quoted YAML (A10) e
  dois stems repetiam perguntas das aulas (A05, A12) —
  reescritos; A14 tinha um terceiro calque ("polemic") sem
  tag — removido para casar com as duas tags declaradas.
