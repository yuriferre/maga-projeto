# M31 — Ofertas e negociação

Spec (`docs/planejamento/02-trilha.md`): entender
uma oferta e negociar com educação. Competências
SPK, REA, WRI. Pré-requisito M28. 4 aulas, a
última [SIM] negociação de oferta.

## Tarefas

- T1: branch `feat/e5-m31` + `module.yaml` + esqueleto `tests/lessons-m31.test.ts`
- T2: 4 padrões BR novos com guardas:
  - `my actual salary` → my current salary ("the actual cost" = real, fora)
  - `job proposal` → job offer ("marriage proposal" fora)
  - `more vacations` → more vacation days ("two vacations a year" fora)
  - `thirteenth salary` → 13th-month pay / year-end bonus
  - mais a tag `vocab.compensation`
- T3: M31-01 — componentes de oferta (base, bonus, equity, benefits, PTO, sign-on)
- T4: M31-02 — negociando ("I was hoping for…", "is there flexibility on…")
- T5: M31-03 — aceitar, pedir tempo e recusar por escrito
- T6: M31-04 — [SIM] negociação de oferta
- T7: avaliação 15 itens + testes de variante
- T8: docs, validação API e fechamento

- Modelo da avaliação ficou com 99 palavras (mín 100) — expandido.
