# M32 — Onboarding em empresa internacional

Spec (`content/levels.yaml`): SPK/WRI/CNF, pré-req M26, 4 aulas,
avaliação "Rubrica dos cenários de primeira semana". Último módulo
do Nível 5 — depois dele vem a avaliação de nível.

## Tarefas

- T1: `module.yaml` + `tests/lessons-m32.test.ts` (esqueleto)
- T2: 4 padrões BR novos com guardas:
  - `new in the company` → new to the team/company
    ("new in town" idiomático, fora)
  - `in my first day` → on my first day
    (só singular — "in the first days" fora)
  - `I need a help` → I need help
    ("a help desk" fora)
  - `the responsible for X` → the owner / who owns
    ("the responsible person", "held responsible for" fora)
  - mais a tag `vocab.onboarding`
- T3: M32-01 — primeiras semanas (se apresentar, mensagem de intro,
  perguntas sem medo)
- T4: M32-02 — construindo relação (1:1s de conhecimento, coffee chat)
- T5: M32-03 — pedindo contexto e documentação ("is there a doc
  for…", "who owns…")
- T6: M32-04 — [SIM] primeira semana em 3 cenários curtos
- T7: avaliação 15 itens + testes de variante
- T8: docs, validação API e fechamento
